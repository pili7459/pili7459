# 日十．大里店 自製全端智能 POS 點餐收銀系統

專為早午餐實體門市打造的現代化收銀（POS）、顧客線上預約點餐、雙向客服與 Google 試算表雲端同步系統。

---

## 🌟 系統核心特色

1. **實體門市收銀端 (`/pos.html`)**：
   - **現場點餐與多層次套餐客製**：支援主餐客製、飲料聯動規格（甜度/冰塊）、多副餐獨立客製化、加購與單品顧客備註。
   - **防誤觸招待機制**：0.5 秒（500ms）內雙擊快速標記免單招待。
   - **三欄一體化收銀台**：左側訂單分類管理、中欄快速找零計算機、右側餐點單行化明細。
   - **打烊日結與現金盤點**：支援各面額紙鈔硬幣盤點計算、自動計算盤差與抽存營收，結算後全螢幕鎖定畫面防誤動。
   - **門市雙向收支簿**：獨立收支鍵盤與常用詞快捷鍵，即時記錄採買支出與額外收入。
   - **員工上下班打卡**：免開後台直接打卡，每日自動重置打卡狀態。

2. **顧客手機線上點餐端 (`/index.html`)**：
   - **線上外帶預約**：支援「盡快取餐」與「指定預約時段（今天/明日預約）」。
   - **Excel 單行化客製排版**：以實心點 `●` 精準標記套餐主餐、飲料、副餐客製規格，清楚不紊亂。
   - **即時雙向客服對話**：顧客點擊右下角懸浮按鈕即可與櫃檯 POS 進行一對一即時通訊。
   - **訂單號碼牌進度追蹤**：下單後自動生成取餐號碼牌，輪詢追蹤店家接單與出餐狀態。

3. **Google 試算表（Google Sheets）雲端雙向同步**：
   - 菜單管理、營業時間、每週公休、促銷折扣碼、員工名單、訂單明細與收支紀錄自動同步至雲端試算表。

請在專案根目錄開啟終端機（PowerShell / 命令提示字元）：

```powershell
npm start


伺服器將在 http://localhost:8080 啟動服務。
現場點餐系統 (POS)：http://localhost:8080/pos.html

指令						說明				使用時機
npm install			安裝相依套件			第一次建立環境、更換電腦或新增套件時執行。會根據 package.json 安裝 Express、ws 等必要套件。
