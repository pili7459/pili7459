# 肚肚風格全端餐飲 POS 系統 (DuDoo-Style POS) v2.1 規格加料視覺化升級版

本版本在 v2.0 基礎上，正式加入**「規格與客製加料視覺化編輯器」**：
1. **後台全視覺化規格管理 (`/admin.html`)**：
   - 在後台可依商品檢視所有規格群組（如加料客製、甜度選擇、冰量選擇）。
   - 支援自由切換「單選 (Radio)」或「多選 (Checkbox)」。
   - 可隨時新增、修改、刪除規格選項與加價金額（如：加起司 +15、特製朝天辣醬 +0）。
   - **內建一鍵套用常用模板**：支援【經典早午餐加料模板】與【茶飲甜度冰量模板】，一鍵自動建立全套規格。
2. **菜單與前台 POS 毫秒連動**：
   - 後台新增或修改規格後，前台 POS 點擊商品立即彈出最新的客製彈窗，即時計算加價總額並自動帶入廚房 KDS 備註。

---

## 啟動教學

```powershell
npm.cmd install
npm.cmd start
```

打開瀏覽器：
- **前台收銀 / 點餐桌況 (POS)**: `http://localhost:3000/pos.html`
- **廚房即時出單看板 (KDS)**: `http://localhost:3000/kds.html`
- **後台管理 (菜單/桌位/規格加料/歷史日結)**: `http://localhost:3000/admin.html`
